# Roadmap

This is a list of candidates, not a promise or a request to install more tooling.

| Candidate | Evidence required before adding it |
|---|---|
| More Desktop walkthroughs | Reproducible behaviour in a named app version/edition, with redacted screenshots |
| Windows helper support | Windows-specific credential, path, permission and subprocess tests |
| More usage schemas | Public or synthetic fixtures, timestamp/counter semantics and deduplication evidence |
| Improved prompt/subagent attribution | Reliable event relationships; unknown values must remain explicit |
| Additional credential providers | Supported public interface, identity verification and no hidden account fallback |
| Translated beginner guides | Maintained parity with canonical workflows and safety notes |

Deliberately excluded: silent account switching, whole-session-store copying, private Desktop DB manipulation, paid cache keepalives, automatic cleanup, sharing credentials, and claims of guaranteed lossless hidden-state migration.

Suggest a specific user problem through the [issue form](https://github.com/AtharvaBondre/ai-workbench-kit/issues/new/choose), including what would improve and what must remain unchanged.
