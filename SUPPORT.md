# Get help

Start with the [visual guide](https://atharvabondre.github.io/ai-workbench-kit/), [script reference](skills/ai-workbench/references/scripts.md), [troubleshooting table](skills/ai-workbench/references/troubleshooting.md), and [compatibility limits](skills/ai-workbench/references/sources.md).

For a toolkit bug, open a [bug report](https://github.com/AtharvaBondre/ai-workbench-kit/issues/new/choose) with:

- Kit version, operating system, Python version and affected client version.
- Whether you used documentation, a script or the AI skill.
- A reproducible example using invented account names and temporary test files.
- Expected and actual behaviour, including the safe error message.

Do not attach your actual profile JSON, `.env`, session store, usage report, credential output or unredacted screenshot. Redact local paths and identifiers even when they are not passwords. Security-sensitive reports belong in the [private security channel](SECURITY.md).

Account access, subscription entitlements, expired credits, invoices, IAM permissions and service incidents belong with the corresponding provider or your account administrator. This project cannot grant model access or promise a spending-limit enforcement policy.

There is no paid support or response-time commitment. Contributions improving clarity, accessibility and synthetic tests are welcome.
