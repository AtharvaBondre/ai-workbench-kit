# AI Workbench Kit contributor rules

This is a public-ready example project. Keep all fixtures synthetic. Never inspect or mutate a contributor's live credentials, session stores, Desktop databases or provider resources to test it.

Read CONTRIBUTING.md. Keep the skill package self-contained and its docs/scripts canonical. Use standard-library Python, preview-first changes, explicit original paths and no credential values in outputs. Test before claiming compatibility. Model names, prices, plan labels and Desktop controls require current evidence.
