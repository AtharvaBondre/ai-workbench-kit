# Project AI usage policy — adapt before enabling

- Preserve existing sessions, working directories, rules and source evidence.
- For new routine coding, use an authorised everyday model and medium effort. Escalate for a specific hard problem; keep paid speed modes deliberate.
- Keep model/tools/stable instructions consistent through a workstream. Do not send cache keepalives or add a caching proxy.
- Search before reading large files. Return relevant output excerpts and keep large artifacts local.
- Use subagents only when useful and authorised; avoid duplicating whole histories across them.
- Keep detailed context in project handoffs with source references. Do not reset/compact/delete active work as an optimisation.
- Keep credentials out of prompts/reports. Verify provider identity and billing separately from local session visibility.
- Review local usage weekly: cache under 85%, premium-model use, subagent activity and prompts over 2% of observed weekly tokens. Treat incomplete metrics as unknown.

This file is a template, not an automatically enforced setting. Add the relevant short rules to your client's supported project instruction file only after reviewing existing instructions.
